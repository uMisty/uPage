# uPage · 个人主页 UI 设计

当前版本采用暖白、炭黑与钴蓝，配合大字号、原创桌面插画、主推作品和开放列表。人物与内容均为公共示例。桌面端和移动端均无顶部导航，没有天气、定位、时钟或语言切换。

## 首屏与阅读顺序

首屏先展示钴蓝实心按钮“阅读博客”，再展示文字入口“查看我的作品”。已移除独立社交入口行和栏目、作品、兴趣的装饰性数字编号，首屏不使用星号装饰。

内容依次为作品、文章与近况、创作工具、代码之外、联系。文章采用开放列表；近况保留钴蓝便签，工具使用深色背景，兴趣使用同一套原创插画。

## 项目区的主次设计

**主推项目**使用通栏大模块：桌面左侧为标题、完整简介和链接，右侧为大幅作品预览；移动端按标题、预览、介绍、操作纵向排列。示例使用“最近推出”标签，Demo 使用实心主按钮。

**其余项目**使用缩略图、简短说明和技术标签组成的横向条目，按钮集中在桌面右侧、移动条目下方。Demo 使用浅色按钮，让主推项目更突出。项目增加时逐条向下排列，不依赖固定条目数。

默认优先选择 `featured: true` 的项目；未指定时选择有效 `releasedAt` 最新的一项。多个主推标记时取其中最新项，同日期保留数据顺序；全部缺少有效日期时使用第一项。其余项目保持原有数据顺序。“最近推出”是示例中显式配置的标签，正式使用时需随项目内容维护。

| 字段 | 用途 |
| --- | --- |
| name / description | 名称和简短介绍 |
| summary | 主推项目的完整介绍，可省略并回退为 description |
| tags / art | 技术标签和示例封面类型 |
| featured | 是否优先作为主推项目 |
| releasedAt | 发布日期，YYYY-MM-DD，用于选取最新项目 |
| releaseLabel | 主推标记文案，省略时显示“主推作品” |
| demoUrl | Demo 地址，独立配置 |
| githubUrl | GitHub 源码地址，独立配置 |

两个链接独立显示和跳转。缺少其中一个地址时只保留另一个入口；都未配置时显示“暂未开放链接”。SVG 使用独立的链接元素，按钮之间没有覆盖整块卡片的点击区域。PNG 只提供视觉预览。

**当前所有项目和发布日期均为虚构示例，Demo 与 GitHub 源码地址都使用 example.com 占位，不对应真实演示和仓库。** 正式使用时替换这两个字段。链接字段支持完整的 HTTP(S) 地址。

## 内容增长时的排列

| 模块 | 桌面端 | 移动端 | 内容增加时 |
| --- | --- | --- | --- |
| 主推作品 | 通栏大模块，文字与预览并排 | 通栏纵向大模块 | 始终选出一个主推作品 |
| 其他作品 | 缩略图、介绍、独立链接的横向条目 | 紧凑图文条目，按钮在下方 | 保持顺序逐条下移 |
| 代码之外 | 等宽三列 | 等宽两列 | 超出当前行后换行 |
| 工具分类 | 三列分类网格 | 单列分类 | 新分类进入下一格或下一行 |
| 每类工具 | 两列条目 | 两列条目 | 条目增加时换行并撑高分类 |

网格中的每行由最高条目决定高度。奇数末行保持原宽度、靠左排列，不拉伸，也不插入空卡片。下方区块随前面的实际高度下移。作品、兴趣或工具为空时隐藏对应区块，空工具分类也不显示。

列表标题与说明按列宽换行，文字宽度使用保守估算；非常长的自定义文案仍需视觉复核。首屏名称与简介沿用固定构图。当前为设计稿生成器，并非已实现的网页响应式布局。

完整页与列表预览的高度由内容计算。PNG 按 2 倍分辨率导出。

- `render-previews.cjs`：生成入口。
- `render-layouts.cjs`：按模块高度依次排版与导出。
- `flow-layout.cjs`：网格排列、文字分行与高度计算。
- `svg-kit.cjs`：颜色、文字、基础形状和 SVG 文档。
- `editorial-art.cjs`：原创桌面场景、作品封面与兴趣插画。
- `modules.cjs`：主推选择、项目展示、两个独立链接、栏目标题。
- `panels.cjs`：文章、近况、兴趣网格与联系区。
- `toolkit.cjs`：可扩展的分类和工具网格。
- `demo-content.json` / `demo-expanded-content.json`：默认与扩展示例。
- `assets/icons/`：Simple Icons SVG、来源与许可。
- `references.md`：参考来源与设计取舍。
- `imagegen-prompts.md`：可选视觉提示词，本版未调用图片生成服务。

## 示例与素材

Alex 为虚构人物，项目、文章、日期、阅读时长、近况和工具配置均为演示内容。联系邮箱为 hello@example.com。插画中的书封与应用也是示例，页脚版权文字不是项目许可证声明。

桌面场景、封面和兴趣插画由本项目 SVG 绘制，未复用参考网站的照片、人物、代码或图像。六个既有品牌图标来自 Simple Icons，扩展工具采用文字缩写。SVG 不依赖外部图片、远程字体或脚本；项目按钮包含导航链接。

## 本地生成与检查

准备 Node.js 和 sharp，在项目目录运行：

```sh
node design/render-previews.cjs
```

脚本生成十一组 SVG 和 PNG。字体使用 Segoe UI、Microsoft YaHei，并回退到 Noto Sans CJK SC / Arial。

本轮检查了两种尺寸下 0、1、2、3、5 个项目的排列、主推优先和发布日期选择、同日期顺序，以及双链接、单链接和无链接情形；同时检查了桌面与移动项目区的 PNG。当前示例链接经过结构检查，未指向真实发布项目。

当前交付为 UI 设计稿及 SVG 预览，未实现或部署网站。后续网页应使用正常文档流、语义化链接与键盘焦点，并支持减少动态效果偏好。
