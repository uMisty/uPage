### 具体调整

- 暖白背景和炭黑文字作为主体，钴蓝用于首屏插画中的笔记本、近况和联系箭头；浅绿作为工具区的辅助色。
- 主推项目将说明与大幅预览并排，其余作品使用紧凑条目；文章改成开放列表，近况使用便签形式，工具使用深色区块，兴趣使用同一套插画。
- 字体、间距、细线和箭头保持一致，同时让不同内容拥有自己的呈现方式。
- 首屏桌面场景、作品界面和兴趣图形均为原创 SVG，没有使用参考站点的照片、模型、代码或品牌标识。

## 首屏插画的调整

抽象几何结与人物介绍的关联较弱。本版改为电脑、笔记本、杯子与绿植组成的创作者桌面，直接回应开发与设计的主题。采用与下方兴趣插画相同的暖色、浅绿和简洁轮廓，钴蓝仅作为笔记本的强调色。场景不包含真人形象、真实房间或个人资料。

- [Krystn Stockbridge](https://www.krystock.com/)：搜索可读内容描述了人物坐在桌前使用电脑的插画，提供了用工作场景表达身份的参考；直接抓取本次超时。
- [Josh W. Comeau 的插画说明](https://www.joshwcomeau.com/contact/)：作者介绍了自己网站上的黏土风格三维日常物件与角色。参考的是用具象插画增加亲和力的思路；本项目继续使用自己的二维 SVG 语言。

未复制上述网站的图像、人物或代码。桌面场景在 `editorial-art.cjs` 的 `workspaceArt` 中绘制，同时适配桌面与移动首屏。

## 模块取舍

- 首页保持“认识这个人 → 看作品 → 读内容 → 了解近况与兴趣 → 联系”的阅读顺序。
- 默认示例包含两个作品和三篇文章；作品支持一个主推大模块加后续自然排列的紧凑条目；兴趣、工具与分类支持增加条目后自然换行。
- 首屏移除独立社交入口行，“阅读博客”为前置主按钮，“查看我的作品”为后置文字入口。
- 栏目与条目不显示装饰性数字编号；兴趣和工具网格不满一行时保持原宽度靠左排列。项目分别配置 Demo 与 GitHub 源码跳转。
- 近期动态使用手动维护的短文案，无须接入实时账户。
- 工具按用途分组，每项使用图标、名称和用途说明，不展示虚构熟练度或成就数字。
- 生活兴趣使用文字与简单图形，不需要照片、地图或个人行踪。
- 履历时间线、朋友链接、音乐播放等可留作未来可选模块，本版不增加。

## 示例与素材

人物、项目、文章、日期、阅读时长、兴趣和动态均为演示数据。邮箱与项目地址使用 example.com 系列占位地址。项目封面和装饰字形由本项目 SVG 绘制；未复用参考个人主页的代码、图片、文章或个人资料。技术品牌图标单独采用 Simple Icons，保留来源与许可。
